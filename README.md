# AI Receptionist Platform

An enterprise-grade multi-tenant AI Receptionist Platform built using FastAPI, SQLAlchemy, Ollama, ChromaDB, and Next.js.

## Vision

This platform enables any organization to create its own AI receptionist capable of:

- Website Chat
- Voice Calls
- WhatsApp Integration
- Knowledge Base Search (RAG)
- Lead Management
- CRM Integration
- Analytics Dashboard

## Tech Stack

### Backend

- Python
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL
- JWT Authentication

### AI

- Ollama
- OpenAI (Optional)
- Gemini (Optional)

### Frontend

- Next.js
- Tailwind CSS
- Shadcn UI
